# Mettelo Brand Guide — Project Library

Use this visual direction for Mettelo Project Studio pages and catalogue interfaces.

## Brand positioning
**Mettelo**

**Tagline:** Where contribution becomes opportunity.

## Core palette

- **Ink** — primary dark text/background: `#141925`
- **Indigo** — secondary dark/accent: `#303861`
- **Amber / Bronze** — value/accent colour: `#CF8D24`
- **Warm Sand** — primary light background: `#F4ECD8`
- **Slate Grey** — secondary text / neutral: `#687381`
- **White** — high-contrast light surface: `#FFFFFF`

## Design direction

- Use **Ink + Amber/Bronze** as the strongest brand pairing.
- Warm Sand is preferred for light page backgrounds rather than stark white everywhere.
- Use White for cards and clean content surfaces.
- Use Indigo sparingly for secondary emphasis.
- Use Slate Grey for supporting text and metadata.
- Avoid unrelated bright colours unless required for data visualisation.
- Maintain generous spacing, clear hierarchy and restrained visual styling.
- Cards should be clean, structured and practical rather than decorative.
- Use the Mettelo mark/wordmark prominently but not excessively.
- Keep the overall impression professional, capability-led and modern.

## Page hierarchy

1. Mettelo brand / wordmark
2. Clear page purpose
3. Strong headline
4. Short supporting context
5. Search/filter or primary action
6. Structured content/cards
7. Mettelo tagline/footer

## Catalogue UX

For the Project Library:
- filter by capability/track;
- filter by sector;
- keyword search;
- project name;
- problem being solved;
- required expertise;
- team size;
- direct repository link.

This structure should remain usable as the catalogue grows to hundreds of projects.
