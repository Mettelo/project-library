# Mettelo Project Studio Catalogue

The **Mettelo Project Library** is the catalogue for our production-style Data, AI and Technology projects.

Each project is built around a realistic organisational problem and gives participants a structured brief, real-world data source, delivery requirements, acceptance criteria and team submission process.

> **How the library works**
>
> **Project Library** → discover the available projects  
> **Project Repository** → read the full project specification  
> **Team Repository** → build and submit the solution

## Team Delivery Model

Each Mettelo project has a **master project repository** containing the challenge specification.

Participating teams create their own delivery repository and use it to evidence:
- analysis and technical work;
- collaboration;
- issues, branches and pull requests;
- documentation;
- final outputs;
- acceptance-criteria completion;
- handover and final submission.

The current direction is to standardise projects around **3–4 person teams** as the catalogue is refined.

## Who Is This For?

The Project Studio is designed for people who want to build evidence of capability through realistic team projects rather than classroom exercises.

Projects are suitable for:
- professionals building practical experience;
- people strengthening their portfolio;
- career changers;
- analysts moving into engineering, data science or AI;
- professionals who want evidence of collaboration and end-to-end delivery.
